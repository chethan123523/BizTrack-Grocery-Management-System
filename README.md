# BizTrack - Grocery Management System

A web-based grocery store management system built using HTML, CSS, JavaScript, PHP and MySQL.

## Features
- Supplier and purchase management
- Customer billing system
- Automatic stock management
- Low-stock and expiry tracking
- Profit and loss reports
- Dashboard with sales statistics

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation
1. Install XAMPP.
2. Copy the project into the htdocs folder.
3. Start Apache and MySQL.
4. Import the project database using phpMyAdmin.
5. Open the project through localhost.
